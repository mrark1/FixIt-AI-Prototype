# FixIt AI Interactive Prototype

This is a front-end-only interactive prototype for the proposed FixIt AI project.

## Run it
1. Extract the ZIP (if using the ZIP).
2. Open `index.html` in a modern browser.
3. No installation or internet connection is required.

## Prototype interactions
- Dashboard navigation
- English / Hindi interface switch
- Guided laptop/desktop symptom intake
- Sample troubleshooting questions
- Illustrative assessment results and safe next steps
- Shareable report text
- Repair-history concept screen
- Technician outcome-entry concept

## Important limitations
This is a UI prototype, not a production diagnostic system. It has no backend, authentication, live AI model, real manuals, verified repair database, live pricing, or real technician connection. Result priorities are illustrative, not validated probabilities. Do not use it to diagnose or repair real devices.
